# gitignore

GitHub's collection of `.gitignore` templates for every language and toolchain.

## Key Paths

- `Global/` — IDE and OS-level ignore patterns (JetBrains, VSCode, macOS, Linux)
- `community/` — Community-contributed templates
- `<Language>.gitignore` — Per-language templates at the root

## Notes

- This file is an example context file distributed by the `example` domain.
- In a real domain, this file describes how the repo fits your project and
  what paths/commands matter for your workflow.
